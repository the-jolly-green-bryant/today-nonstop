# Today Nonstop

Today Nonstop is a dialog-driven choose-your-own-adventure platform. It loads data from a JSON file and presents the adventure to the player in a messenger format.

# Editor

All game data is stored in `src/app/game-data/dialog.json`, but the best way to interface with this file is through the purpose-built editor. To run the editor:

- Serve the Ionic project.
- Navigate to `/editor`.
